# Prepare a Google Cloud MCP server

This guide prepares a custom Model Context Protocol (MCP) server hosted on
Google Cloud Run and protected by Google OAuth 2.0. It covers only Google Cloud
configuration. Return to the [integration guide](../README.md) after completing
the checkpoints.

The screenshots use generic example values and contain no account, project,
client, token, or secret identifiers.

## What you will produce

- A public HTTPS MCP endpoint such as `https://<SERVICE_HOST>/mcp`.
- A Google Auth Platform application with the required audience and scopes.
- A Web application OAuth client whose redirect URI is supplied by the caller.
- A client ID and client secret stored outside source control.
- A Cloud Run service that accepts tokens only for that client ID.

## Before you start

- A Google Cloud project with billing enabled.
- Permission to configure Google Auth Platform and deploy Cloud Run services.
- MCP server source code, or a server based on Google's maintained guidance.
- The exact OAuth redirect URI generated by the consuming application.

Google requires an exact redirect URI match, including scheme, host, path,
case, and trailing slash. Do not copy one from an example.

## Placeholder convention

| Placeholder | Meaning |
| --- | --- |
| `<GOOGLE_CLOUD_PROJECT_ID>` | Google Cloud project ID |
| `<REGION>` | Cloud Run region |
| `<SERVICE_NAME>` | Cloud Run service name |
| `<MCP_SERVER_BASE_URL>` | Cloud Run service URL without `/mcp` |
| `<MCP_ENDPOINT>` | Complete MCP URL |
| `<OAUTH_REDIRECT_URI>` | Exact callback URL supplied by the consuming application |
| `<GOOGLE_OAUTH_CLIENT_ID>` | Google Web application client ID |
| `<GOOGLE_OAUTH_CLIENT_SECRET>` | Google client secret; never commit it |
